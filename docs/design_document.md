# 茉莉酱学习乐园 - 设计文档

## 1. 项目概述

### 1.1 产品定位
- **目标用户**: 小学二年级学生
- **核心玩法**: 知识问答 + 宠物养成
- **教育目标**: 巩固课堂知识，培养学习兴趣

### 1.2 核心角色
- **茉莉酱**: 二年级小学生，羊角辫，戴眼镜，可爱活泼
- **猪小弟**: 茉莉酱的宠物小猪，需要喂养和照顾

---

## 2. 游戏系统

### 2.1 知识问答系统
- **题库规模**: 每科300+题，共1200+题
- **科目分类**: 语文、数学、英语、科学
- **难度分级**: 简单、中等、困难
- **奖励机制**: 
  - 答对: 基础金币 + 连续答对加成
  - 答错: 显示正确答案，无惩罚

### 2.2 猪小弟养成系统
- **属性**: 饱食度、快乐值、成长值、等级
- **互动**: 喂养、玩耍、抚摸、装扮
- **成长**: 升级解锁新外观和能力

### 2.3 金币经济系统
#### 获取途径
- 答题奖励（基础来源）
- 每日任务
- 连续登录
- 成就解锁
- 分享奖励

#### 消耗途径
- 购买食物
- 购买道具
- 购买装扮
- 解锁新功能

### 2.4 商城系统
- **食物**: 5种，不同效果
- **道具**: 4种，增加快乐值
- **装扮**: 多品类，解锁式

### 2.5 每日任务系统
- 每日5个任务
- 任务类型: 答题、喂养、互动、学习时长
- 奖励: 金币 + 道具

### 2.6 学习报告
- 每日/每周/每月统计
- 答题正确率趋势
- 学习时长记录
- 知识点掌握分析

### 2.7 成就系统
- 10+成就类别
- 学习类、养成类、收集类

## 3. 技术架构

### 3.1 技术栈
- **框架**: Kivy (Python)
- **数据存储**: JSON 本地存储
- **音效**: pygame.mixer
- **动画**: Kivy Animation + 帧动画
